#+title: Project templates

Copy =rust/= or =python/= for a new project, rename =CHANGEME=/=changeme=
throughout, and remove what is not needed. Engineering guidance lives in
=guidance/rules/{rust,python}.md=; the templates implement its build gates.

* Gates

- Rust: =cargo check --all-targets=, =cargo clippy --all-targets=, =cargo test=.
  Clippy rejects bare =unwrap()=; rustc forbids unsafe code.
- Python: =uv sync=, =ruff check=, =ruff format --check=, =mypy src tests=,
  =pytest=. The template includes a build backend, strict typing, dependency
  locking and a CLI smoke test.

* Limits

A passing gate does not establish HTTP pagination, explicit timeouts, secret
hygiene or bounded asynchronous work. Review those requirements directly using
=python-silent-failure.md= and =rust-runtime-hazard.md= under =guidance/rules/=.
Ruff's =S113= checks =requests= calls, not =httpx= calls.

Diagnostics belong on stderr so stdout remains pipeable. The Python template
sets =structlog.PrintLoggerFactory(file=sys.stderr)= and tests CLI stdout.

Change a template and its guidance together, then run the gate on a fresh copy.

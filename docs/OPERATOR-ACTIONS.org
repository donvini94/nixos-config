* Access and identity
** TODO Split the shared =nix= account
:PROPERTIES:
:ADDED: 2026-08-29
:END:

=hosts/alucard/users.nix= defines one =nix= account whose =authorized_keys=
holds Vincenzo's, Marius's and Kyrill's keys, and it is in the =docker= group —
which is root-equivalent, because the Docker API can mount =/= into a
privileged container. Three people share one Linux identity, so nothing in the
logs attributes an action to a person.

Teleport was going to solve this. It was dropped on 2026-08-29 as
disproportionate for a two-person MVP, so the plain fix stands on its own:

- give Marius and Kyrill their own accounts with their own keys, or remove
  their keys if they no longer need shell access;
- move the game-server containers off a human-shared account onto a dedicated
  service account;
- drop =docker= from any account that does not genuinely need root.

None of this needs new software. Worth doing before anyone outside the two
founders gets shell access.

=renovate.json= is well configured — =docker:pinDigests=,

run*. With =dependencyDashboard: true= a first run would have opened an issue;

So the control described in =README.org= ("Renovate pins container digests and
GitHub Action SHAs") was aspirational. Digests are now pinned by hand; without
Renovate they will simply rot instead of drifting.

Install the app at https://github.com/apps/renovate for =donvini94/nixos-config=.

*Two things to expect after installing:*

- =schedule= is ="* 22-23 * * 1-5"=, so Renovate only acts on weekday evenings
  between 22:00 and 23:00. Install it on a Saturday and nothing at all happens
  until Monday night — that is the schedule, not a failure.
- Renovate needs *write* access to open branches, PRs and the dependency
  dashboard issue. Read-only access produces silence.
That is the whole task — nothing in the repo needs changing. The config was
validated with =renovate-config-validator=, and every custom manager was tested
against its target file: all five dependencies match, including the Trivy digest
pinned on 2026-08-29.

** TODO Rotate the nginx basic-auth credential

=secrets/htpasswd= was tracked in Git. It is now removed from the working tree
and lives in SOPS as =nginx/htpasswd=, mounted at =/run/secrets/nginx/htpasswd=

Removing the file does *not* remove it from history, so the hash is still an

#+begin_src bash

shred -u /tmp/htpasswd
#+end_src

Then update =docker login registry.dumusstbereitsein.de= and any WebDAV client.
